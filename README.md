# Vitrines Pro

Portfolio de démos de sites pour commerces, avec offre, devis sur mesure, prise de 2e rendez-vous et espace administrateur. Fonctionne hors ligne une fois installé sur le téléphone.

- Application : `index.html` (installable, ajouter à l'écran d'accueil)
- Synchronisation en direct (facultative) : voir `GUIDE-SYNCHRO.md`

Les noms, photos, prix et avis des démos sont fictifs.
